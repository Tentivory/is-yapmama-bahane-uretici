# İş Yapmama Bahane Üretici

## Dünyanın En Önemli Projesi

Bu proje, insanlığın en büyük sorunlarından biri olan "iş yapma zorunluluğu"na karşı geliştirilmiş devrim niteliğinde bir araçtır. Yıllar süren (yaklaşık 3 dakika) araştırma ve geliştirme sonucunda ortaya çıkan bu yazılım, prokrastinasyonu bilimsel bir disipline dönüştürmektedir.

### Özellikler

- %100 bilimsel olarak doğrulanmış bahaneler (doğrulama süreci: rastgele seçim)
- Gerçek zamanlı bahane üretimi (3 saniye sürer, çünkü acele etmemek lazım)
- Kedi, kahve, kuantum fiziği ve ay tutulması gibi ileri teknoloji bahaneler
- Sıfır bağımlılık (sadece Python, ama o da uyuyor)

### Kurulum

```bash
git clone https://github.com/Tentivory/is-yapmama-bahane-uretici.git
cd is-yapmama-bahane-uretici
python bahane_uretici.py
```

### Kullanım

Programı çalıştırın. Bahane üretilir. İşi yapmayın. Tebrikler, verimliliğinizi sıfıra indirdiniz.

### Katkıda Bulunma

Yeni bahane önerileri kabul edilir. Ancak lütfen önce bir bahane üretin ve neden katkıda bulunamadığınızı açıklayın.

### Lisans

Bu proje MIT lisansı altındadır. Yani istediğinizi yapabilirsiniz, ama yapmayın, tembellik yapın.

### Uyarı

Bu yazılım kullanıldığında üretkenlik düşebilir. Yan etkileri: rahatlama, gülme, iş yapmama.
